# My First Web Page

ai를 활용하여 간단한 웹페이지를 제작한 후, ai 생성 원본을 간단하게 직접 수정하며 Git/GitHub를 이용한 버전 관리와 Vercel 배포 과정을 실습 했습니다


- Vercel: https://2026-oss-assign01-vert.vercel.app

- index.html: https://2026-oss-assign01-vert.vercel.app/index.html

- index2.html: https://2026-oss-assign01-vert.vercel.app/index2.html

### Key Learning
- Git으로 add, commit, push하는 흐름을 배웠다

- GitHub을 Vercel과 연결해서 배포, 재배포 하는 방법을 배웠다

- Vercel에서 연결된 웹사이트는 index.html만 보여주고 index.html을 접근을 하려면 직접 입력해야 한다는 것을 배웠다

### Development Flow
- VS Code 에서 코드를 작성 -> 터미널에서 Git 관리 -> GitHub에 push -> Vercel에서 수정된 부분 반영해서 재배포

### Code Modification 
- 자기소개 텍스트 내용 변경
- 배경색 변경
- 이미지 추가

### Problem & Solution
-Vercel에서 배포된 주소로 들어가도 index2.html은 보이지 않고 index.html만 보여서 배포에 문제가 생긴 줄 알았다.
- index2.html은 직접 주소를 입력해야 들어갈 수 있다는 것을 알게 되었다.

### Reflection
DevTools 에서 수정해도 실제로는 바뀌지 않아서 수정할 부분들을 직접 확인해보고 반영 여부를 결정 할 수 있다는 것을 알게 되었다
